# RidgeMD

Physician-founded telehealth for Tennessee — [ridgemd.com](https://ridgemd.com).

This repository was branched from the SpryMD (`sprymd.ai`) codebase with full RidgeMD branding.

## Stack

- Vite + React + TypeScript
- Tailwind / shadcn/ui
- Hosted Supabase + Stripe
- Bun for package management

## Commands

```bash
bun install
bun run dev    # http://localhost:8080
bun run test
bun run build
```

## Domain

Production domain: **ridgemd.com** (and www).
